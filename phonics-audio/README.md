# phonics-audio — 파닉스 실제 발음 음성

해율이 스터디 보드(`haeyuli-english-board.html` · `haeyuli-study-mobile.html`)의 파닉스 탭이
브라우저 음성(`speechSynthesis`) 대신 쓰는 음성 파일 모음입니다.
`"buh"`, `"bee"`처럼 글자 이름을 읽던 소리를 없애고, 음가(phoneme)·단어·문장을 실제 목소리로 들려줍니다.

## 구조

```
phonics-audio/
  snd/<키>.mp3     음가 49개 — a~z, sh, ch, th(θ), thv(ð), ck, ng, st, sp, tr, ll, ar, air, ree, er, ee, ea, se, oo, oe, a_e, i_e, o_e, u_e
  word/<단어>.mp3  단어 75개 — 보드의 파닉스 단어와 1:1
  sent/L<번호>-<0~2>.mp3  문장 42개 — 레슨 14 × 문장 3
```

파일 이름이 곧 키입니다. 문장 단어 타이밍은 HTML 안 `PH_SENT_TIMING`에 들어 있어,
재생할 때 단어가 노래방처럼 짚입니다.

## 만든 방법

- **a~z 26개 음가**: [Open Letter Sounds](https://purplecomputerorg.github.io/openlettersounds/)(CC0)의
  `sounds/en-us/marin/*.wav`. 파닉스 교사 말투로 "pure sound"만 담도록 만든 클립이라
  파열음에 `uh`가 붙지 않고, 마찰음은 길게 이어집니다. 라이선스 CC0(출처 표기 불필요).
- **나머지 음가(sh·ch·th·ng·st·sp·tr·장모음·ar·air·ee·oo·oe·se·er·ree 등)**: 단어 음성에서
  해당 음가 구간만 잘라 씁니다(예: sh ← ship 앞부분, ch ← cheese 앞부분, ng ← sing 끝부분,
  a_e ← 알파벳 A 이름). 구간 경계는 5ms 단위로 파형·스펙트럼을 재서 잡았고,
  마찰음(sh·th·ð)은 자연스럽게 이어지도록 짧은 구간을 크로스페이드로 늘렸습니다.
- **단어 75개 · 문장 42개**: AI 음성 합성(미국 여성 음성)으로 만들고, 앞뒤 무음을 잘라
  같은 크기(RMS −22 dBFS 근처, 피크 −1 dB 이하)로 맞췄습니다.
- 모든 파일은 모노 24kHz MP3(56~64kbps)입니다.

## 검증

- 166개 파일 전부 디코드·길이·피크·RMS 검사: 무음 0개, 클리핑 0개.
- 음가 49개는 음향 특징으로 확인했습니다 — 마찰음은 무성·고주파(s 8.4kHz, sh 5.1kHz, th 6.0kHz),
  비음은 유성·저주파(m 550Hz, n 791Hz, ng 420Hz), 모음은 유성·중심주파수 대역.
- 단어 75개는 음성 인식으로 재확인해 모두 알아듣는 단어로 인식됐습니다.
- 보드에서 14개 레슨 × (소리·타일·단어·챈트·합치기·문장)을 모두 눌러 404 0건, 콘솔 오류 0건.

## 보드에서의 동작

- 음가 카드·타일을 누르면 `snd/`, 단어 카드를 누르면 `word/`가 재생됩니다.
- `🎵 음가+단어 챈트`: 음가 → 음가 → 단어 (파닉스 몬스터식 사운드 챈트).
- `🔊 합쳐서 듣기`: 타일 음가를 차례로 → 마지막에 단어.
- 문장의 `🔊 전체 듣기` / `🐢 천천히`: 문장 음성 + 단어 하이라이트.
- 오프라인이거나 파일을 못 받으면 이전처럼 브라우저 음성으로 자동 대체됩니다.
